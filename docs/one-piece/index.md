# One Piece

Our analysis of *One Piece* explores ambition, adventure, character introductions, world-building, and long-form storytelling.

## Storytelling questions

- How does the series establish Luffy's dream and personality?
- How does it reveal the world without overwhelming the audience with exposition?
- How do supporting characters clarify the protagonist's values?
- How can early episodes create momentum for a much longer journey?
